# 🚗 Car Wash MVP — Система записи на мойку (3 бокса)

Современный сервис для онлайн-записи автомобилей на мойку. Система автоматически распределяет записи по 3 свободным боксам с шагом в 15 минут.

## ✨ Особенности проекта
*   **3 независимых бокса**: Умная логика проверки доступности времени.
*   **5 программ мойки**: От быстрой технической до полного детейлинга.
*   **Гибридная авторизация**: Вход по Email или номеру телефона (заглушка для MVP).
*   **Личный кабинет**: История записей и возможность отмены.
*   **Админ-панель**: Визуализация очереди (Timeline) для управления боксами.

## 🛠 Технологический стек
*   **Frontend**: React 18+ (Vite), TypeScript.
*   **UI & Styling**: Mantine UI, Tailwind CSS, Lucide Icons.
*   **Database & Auth**: Supabase (PostgreSQL).
*   **Date Management**: Day.js.

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd car-wash-mvp
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка окружения
Создайте файл `.env` в корне проекта и добавьте ваши ключи от Supabase:
```env
VITE_SUPABASE_URL=https://supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```

### 4. Запуск проекта
```bash
npm run dev
```

## 🗄 Структура БД
Проект использует две основные таблицы в Supabase:
*   `wash_programs`: Список услуг, их цена и длительность.
*   `bookings`: Данные о записях (время, бокс, клиент, статус).

## 🛡 Безопасность
В проекте настроены **Row Level Security (RLS)** политики:
*   Программы мойки доступны всем для чтения.
*   Записи могут создавать все (включая гостей).
*   Просматривать свои записи могут только авторизованные владельцы.
